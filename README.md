## 项目简介：基于知识蒸馏的轻量级中文文本增强模型开发

本项目从零构建了一个约120M参数的Transformer解码器结构语言模型，尝试去替换LLMInputEnhancer中的Qwen3.5-0.8b模型，完整实现了语言模型从预训练到指令微调的全流程开发。

项目整体分为三个核心阶段：
1.  **模型架构与预训练**：基于PyTorch实现自定义Transformer解码器模型，通过大规模中文通用语料完成基础语言能力预训练，让模型具备基础的中文理解与生成能力。
2.  **蒸馏数据构建**：采用“通用指令集+大模型蒸馏”的低成本方案，基于Belle、Adgen公开指令数据集，通过开源大模型生成带标准答案的微调数据，构建面向文本润色、摘要任务的专属指令数据集。
3.  **轻量化指令微调**：基于LoRA低秩适配技术对预训练模型进行微调，在仅训练少量参数的情况下完成指令对齐，同时避免小数据集过拟合，最终得到可在单卡8G显存环境下运行的轻量化文本增强模型。

项目日志：

本项目完整实现了轻量级语言模型的开发链路，验证了小模型在特定文本处理任务上的可行性，为低资源场景下的轻量级NLP模型开发提供了可复现的实现方案。
